# Centaur Context agent client

This package provides the constrained Python client and command-line interface
for Centaur Context's authenticated agent API. It is designed to be loaded by a
Centaur installation as an approved tool; it is not a standalone agent runtime.

See the main [Centaur Context repository](https://github.com/bradwmorris/centaur-context)
for setup, API boundaries, and compatibility information.
